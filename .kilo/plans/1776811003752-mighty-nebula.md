# Plan: Make Hardcoded Strings Translatable

## Overview
The project already has a robust localization setup with:
- ARB files (`lib/l10n/app_en.arb`, `lib/l10n/app_es.arb`)
- `AppLocalizations` generated class
- `l10n.yaml` configuration

However, several hardcoded strings were found that should be localized.

## Hardcoded Strings Found

### 1. `asymmetry_test_screen.dart` (lines 246-264)
**Dialog with hardcoded strings:**
```
'Incomplete Test'
'You have $leftCount left-leg and $rightCount right-leg jump(s). It is recommended to record 3 per leg for accuracy. Save anyway?'
'Save Anyway'
```
**Fix:** Add new keys to ARB files for this incomplete asymmetry dialog.

### 2. `asymmetry_test_screen.dart` (line 663)
**Hardcoded label:**
```
'ASYMMETRY RESULT'
```
**Fix:** Add localization key `asymmetryResult`.

### 3. `fatigue_test_screen.dart` (lines 272-280)
**Hardcoded labels in `_fatigueStatus` getter:**
```
'Optimal'
'Moderate Fatigue'
'High Fatigue'
```
**Fix:** These are used in a getter returning a tuple. Already have localized versions (`l.optimal`, `l.moderateFatigue`, `l.highFatigue`) but the getter uses raw strings. Refactor to use localizations.

### 4. Dashboard Fallback Strings (`dashboard_screen.dart`)
**Lines 449-450, 462-463:**
```
'${height} cm'
'No data'
'${rsi} RSI'
```
**Fix:** Add `noData` and `cmUnit` keys to ARB files.

### 5. `cmj_baseline_screen.dart` (line 328)
**Chip bar label:**
```
'${s.athleteName} (${s.validJumpCount}/3)'
```
**Fix:** Already has `athleteJumpProgress` key but not used here. Update to use localization.

### 6. Unit Strings - Various Files
**Common units hardcoded:**
- `'cm'` (centimeters)
- `'kg'` (kilograms)
- `'ms'` (milliseconds)
- `'W/kg'` (watts per kilogram)
- `'—'` (dash for null values)

**Fix:** Add keys: `unitCm`, `unitKg`, `unitMs`, `unitPerKg`, `dashPlaceholder`.

### 7. Chart Axis Labels (`group_overview_screen.dart`)
**Lines 182-189:**
```
'L', '0', 'R' (for Left/Right axis labels)
```
**Fix:** Add `chartAxisLeft`, `chartAxisCenter`, `chartAxisRight` keys.
